# 📊 Análisis de Ventas de Retail (Retail Store Sales Analytics)

---

## 🎯 Objetivo del Proyecto
Diseñar e implementar un proyecto analítico completo de extremo a extremo, abarcando la ingeniería de datos en SQL para la limpieza y transformación de registros transaccionales, y la construcción de un panel visual ejecutivo (dashboard) en Power BI Desktop con un diseño moderno y una arquitectura de datos optimizada basada en medidas DAX para un portafolio profesional.

## 🛠 Herramientas Utilizadas
* SQL (SQLite / DBeaver): Gestión de bases de datos, creación de vistas (views) para limpieza de datos nulos y optimización de cálculos a nivel de fila (Row-Level Calculations).
* Power BI Desktop: Modelado de datos dimensional, creación de medidas DAX avanzadas (Total Revenue, Average Order Value, Total Transactions, Count of Discount Applied) y diseño de interfaz gráfica (UI/UX) enfocada en la eficiencia de memoria RAM.
* Git & GitHub: Control de versiones y documentación del portafolio profesional.

---

## 💡 Principales Insights
* Métricas Financieras Generales: La facturación auditada alcanzó un Total Revenue de $988.51K, con un volumen de 8K transacciones registradas y un Ticket Medio (Average Order Value) de $130.43 por compra.
* Descuentos y Promociones: Se identificó la aplicación de descuentos en un total de 957 transacciones dentro del periodo analizado, permitiendo evaluar el impacto de las estrategias comerciales.
* Canales de Pago: Distribución equilibrada entre los métodos de pago habituales, liderada por Cash (34.78%), seguido de Credit Card (32.78%) y Digital Wallet (32.45%).
* Tendencia Temporal: La evolución mensualizada entre 2022 y 2025 muestra un comportamiento de ventas estable con patrones de consumo consistentes a lo largo del tiempo.
